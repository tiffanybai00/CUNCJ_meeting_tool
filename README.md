# CUNCJ 会议纪要生成器

本工具是一个将*语音转录文本*自动生成*中文会议纪要*的小工具
- prompt.md 会一直迭代直到生成满意的纪要

🔗 **工具地址：** [tiffanybai00.github.io/CUNCJ_meeting_tool](https://tiffanybai00.github.io/CUNCJ_meeting_tool)

## 使用前准备

需要一个 **DeepSeek API Key**，首次使用时填入工具即可，之后会自动记住，无需重复填写。

## 使用步骤

1. 打开工具地址
2. 将语音转录内容完整粘贴到输入框
3. 点击「生成纪要」
4. 核对生成内容，重点检查：
   - 人名、公司名、项目名是否正确
   - 数字是否与录音一致
   - 有无遗漏的议题
5. 手动修改后，点击「导出」下载 `.docx` 文件

## 注意事项

- 生成内容仅供参考，**务必人工核对后再使用**
- 专有名词（人名、项目名、公司名）AI 可能识别有误，请以录音为准
- API Key 仅保存在你自己的浏览器中，不会上传或共享
